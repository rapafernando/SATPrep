Put it on your home screen

It opens full screen with its own icon, like any app. It is still the website, so updates arrive by themselves. Nothing to download from an app store.

iPhone or iPad (use Safari)

  1. 1Open this site in Safari.
  2. 2Tap the Share button (the square with an arrow pointing up).
  3. 3Scroll and tap Add to Home Screen, then Add.

Android (use Chrome)

  1. 1Tap Install in the banner, or open the ⋮ menu.
  2. 2Choose Install app (or Add to Home screen) and confirm.

The Install now button shows only on browsers that allow it.

Computer (Chrome or Edge)

Click the install icon at the right end of the address bar, then Install.

After installing, open it from the icon. You stay signed in on that phone.
